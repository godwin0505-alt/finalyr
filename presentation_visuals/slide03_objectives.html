Project Objectives

Seven primary objectives driving the TempWatch Insights system

1
🔌

Design Verilog HDL Comparator

16-bit Q8.8 fixed-point temperature comparator in RTL Verilog with combinational logic

2
⚙️

Compile via Verilator

Convert HDL to native C++ binary using Verilator for software-invocable hardware execution

3
🖥

Build REST API Backend

Node.js/Express/Prisma server that spawns the compiled Verilog binary via child_process

4
🗂

Ingest 25 Years of Climate Data

Historical NASA POWER data (2000-2024): temperature, humidity, precipitation, wind, pressure

5
📈

Serve SARIMAX Forecasts

Pre-generated SARIMAX temperature predictions (2025-2035) with seasonal + exogenous factors

6
💻

Interactive React Dashboard

5 analytical views: Overview, Historical, Forecast, Climate Data, Verilator Debug

7
📑

Log Every HDL Comparison with Timing Metrics

Comprehensive audit log capturing temp values, fixed-point encodings, Verilator result, execution time (ms), and method (HDL vs fallback) for every comparison
