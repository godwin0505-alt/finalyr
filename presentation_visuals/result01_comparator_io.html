POST /compare endpoint — Every comparison passes through compiled Verilog binary

Tools Used: Verilog HDL (comparator.v) compiled via Verilator to native C++ binary (obj_dir/Vcomparator). Backend invokes it using Node.js child_process.spawn(). Results logged to SQLite via Prisma ORM. Frontend triggers via api.compareTemperatures() using the Fetch API.
Libraries: Express 5, Prisma 7.2, React 18, Framer Motion (animation), Lucide React (icons).

Insight: The Q8.8 fixed-point encoding (multiply by 256) ensures that even fractional differences as small as 0.004°C (1 LSB = 1/256 = 0.00390625°C) are correctly compared by the Verilog hardware. The sub-5ms execution time includes the full process spawn overhead, proving the HDL path is viable for real-time dashboard use. Every comparison is atomically logged to the ComparisonLog table with input values, fixed-point encodings, result, and timing — providing a complete audit trail.
