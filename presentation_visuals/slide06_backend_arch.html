💚 Climate API

GET /api/climate/exogenous

Yearly/monthly/daily aggregates with stats, correlations, and data range

↓ Prisma → SQLite (ClimateData)

🔌 Compare API

POST /compare
GET /compare?a=X&b=Y

Execute Verilator binary, parse stdout, log result to DB

↓ spawn() → Vcomparator → Prisma → ComparisonLog

📈 Forecast API

GET /api/temperature/prediction
POST /api/temperature/forecast-comparison

2024 vs 2025 comparison, historical vs any forecast year

↓ Prisma → ForecastData + ClimateData + spawn()

📊 Historical API

POST /api/temperature/historical

Year-to-Year or Day-to-Day comparison with per-pair Verilator runs

↓ Prisma + batch spawn() → ComparisonLog

📑 Logs API

GET /api/comparison-logs
GET /api/comparisons/history

Paginated comparison logs with window statistics

↓ Prisma → ComparisonLog

💚 Health & Admin

GET /health
POST /api/admin/fix-unknown-logs

DB connectivity check, fix legacy Unknown results

↓ Prisma $queryRaw → SELECT 1
